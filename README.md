# Pomodoro Timer

A simple Pomodoro Timer web application built using HTML, CSS, and JavaScript.
This project was created to practice JavaScript concepts such as DOM manipulation, event handling, timers, and managing application state while building a practical productivity tool.

## Live Demo
https://okunyomihoghenetega.github.io/Pomodoro-Timer/

## Features
- Pomodoro, short break, and long break modes
- Start and pause timer controls
- Sound notifications when a session ends
- Automatic switching between work and break sessions
- Different themes for each timer mode
- Completion messages and timer animations
- Responsive design for mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript

## What I Practiced
- Working with the DOM
- Adding and handling user interactions
- Using setInterval() to create a countdown timer
- Managing application state with variables
- Working with audio in JavaScript
- Creating responsive layouts with CSS
